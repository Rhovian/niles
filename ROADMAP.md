# Roadmap

Where Niles is headed. These are directions, with no set dates or promised order.
Star and watch the repository to follow progress.

- **Full TUI:** manage projects, agents and their work from a complete terminal interface.
- **Audio operator:** talk to your lead and hear updates through a voice interface.
- **Dynamic free models:** discover available free models as offerings change and make them
  available for skill bindings.
- **Homebrew-core:** install with plain `brew install niles`, without adding a tap first.
  The tap is already available; inclusion in homebrew-core waits on Homebrew's notability bar.
- **More agent types:** expand beyond the current families, with candidates such as OpenCode,
  Cursor CLI, Grok CLI and Devin.
- **Permission policies:** configure per-agent allowed commands and hooks.
- **Configurable approvals:** choose per skill whether its agent bypasses approval prompts. Today
  workers bypass them and the operator-facing entry agent keeps them.
